# Community Launch Kit

Use this page after `v0.1.0-preview.1` is available on GitHub Releases.

## Short Pitch

SkillOS helps your coding agent stop guessing.

It looks at what skills and tools are installed, understands what the task needs, recommends the right skill chain, keeps risky actions under a safety profile, and explains why it selected or skipped capabilities.

## One-Liner

```text
SkillOS is a local-first mission control for coding-agent skills, MCP tools, plugins, rules, and client workflows.
```

## Show HN Draft

```text
Show HN: SkillOS - local-first mission control for coding-agent skills

I built SkillOS because installing agent skills is not enough. Once a coding agent has many skills, MCP tools, rules, and plugins, the user still has to know which one to ask for.

SkillOS inventories local capabilities, turns them into capability cards, recommends staged skill chains, records explainable local decisions, accepts feedback, exposes an MCP server, and generates presets for Codex, Claude Code, Cursor, Windsurf, OpenHands, OpenClaw, and OpenClaw-like clients.

The goal is simple: say what you want, not the skill name.

Repo: https://github.com/xiaoxiaofeiya/SkillOS
Install: npx skills add xiaoxiaofeiya/SkillOS -g
```

## Reddit / Discord Draft

```text
I am building SkillOS, a local-first orchestration layer for coding-agent skills.

The problem: agents can now use many skills, MCP tools, plugins, hooks, and rules, but users still have to know which capability to invoke.

SkillOS discovers installed skills, recommends staged skill chains, explains selected/skipped candidates, keeps risky actions behind safety profiles, and exposes a stdio MCP server.

It supports Codex, Claude Code, Cursor, Windsurf, OpenHands, OpenClaw, and OpenClaw-like runtimes.

GitHub: https://github.com/xiaoxiaofeiya/SkillOS
```
