# Release and Distribution

SkillOS public preview distribution supports multiple paths:

- GitHub repository install by clone.
- Zip artifact generated by `npm run pack:zip`.
- Agent Skills / skills.sh install.
- Claude Code plugin marketplace install.
- npm preview packages.
- MCP Registry and MCP directory submissions.
- OpenClaw / ClawHub submissions.

## Local Release Check

```bash
npm run release:local
```

This runs:

- `npm test`
- `npm run pack:zip`
- `npm run pack:verify`
- `npm run pack:npm`
- `npm run verify:install`

Before a public preview publish, also run:

```bash
npm run verify:install:network
npm run verify:publish-readiness
npm run publish:preview:dry-run
```

## Zip Package

```bash
npm run pack:zip
node packages/cli/dist/index.js pack verify
```

The zip is written to:

```text
dist/skillos.zip
```

The zip excludes:

- `.skillos/`
- `node_modules/`
- `dist-presets/`
- TypeScript build-info files
- local logs
- `.env*`
- token/API-key-looking files

## GitHub Actions

The CI workflow builds, tests, packages, verifies, and uploads `skillos.zip` as an artifact.

The release workflow runs on tags matching `v*` and attaches:

- `dist/skillos.zip`
- `dist/pack-verification.json`

Create the public preview release tag:

```bash
git tag v0.1.0-preview.1
git push origin v0.1.0-preview.1
```

The release workflow attaches:

- `dist/skillos.zip`
- `dist/pack-verification.json`

## npm Preview

The root workspace is private. The four workspace packages are npm-ready:

- `@skillos/core`
- `@skillos/cli`
- `@skillos/mcp-server`
- `@skillos/adapters`

Dry-run packaging:

```bash
npm run pack:npm
```

Do not run a real npm publish until package ownership and scope access are confirmed.

Preview publish order:

```bash
npm publish --workspace @skillos/core --access public --tag preview
npm publish --workspace @skillos/adapters --access public --tag preview
npm publish --workspace @skillos/mcp-server --access public --tag preview
npm publish --workspace @skillos/cli --access public --tag preview
```

The preferred orchestrated command is:

```bash
npm run publish:preview:live
```

If a platform lacks auth or local CLI support, the publish script must report `skipped` with a reason such as `auth_missing`, `tool_missing`, or `scope_unavailable`.
