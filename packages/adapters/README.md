# @skillos/adapters

Client adapters and presets for SkillOS.

Supported adapters:

- Codex
- Claude Code
- Cursor
- Windsurf
- OpenHands
- OpenClaw
- OpenClaw-like variants through manifest and probing

Adapters render install plans, preset files, diffs, setup verification, and invocation hints. Routing logic stays in `@skillos/core`.
